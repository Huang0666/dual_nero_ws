# Agent 文档入口

## 作用

本目录用于帮助 agent 快速进入项目上下文，不要求完整叙事，但要求结构清晰、规则明确、入口稳定。

## 推荐阅读顺序

1. [current_context.md](current_context.md)
2. [rules.md](rules.md)
3. [doc_map.md](doc_map.md)
4. [repo_map.md](repo_map.md)
5. [handoff.md](handoff.md)

## 当前文档

- [current_context.md](current_context.md)：当前阶段和最近结论
- [repo_map.md](repo_map.md)：仓库结构与关键文件入口
- [doc_map.md](doc_map.md)：代码改动到文档更新的映射
- [rules.md](rules.md)：文档与协作硬规则
- [handoff.md](handoff.md)：当前会话交接摘要
