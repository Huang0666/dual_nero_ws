# P6 文档

## 作用

定义 P6 的目标、前置依赖和当前不展开的边界，避免在 P5 尚未稳定前提前扩散需求。

## 当前阶段定位

P6 的主题是：

- 视觉接入
- 感知结果入规划
- 简单抓取 / 操作闭环

它不是当前立即实现阶段，而是下一阶段规划。

## 前置依赖

进入 P6 前，至少应满足：

1. `P5-Sim` 已形成稳定的双臂协同最小样例
2. `P5-Real` 已能在真实工位下给出可信的协同 / 避障结论
3. 相机、坐标系和标定链路已明确
4. 至少明确一个简单感知任务样例

## P6 第一版目标

P6 第一版建议只追求：

- 视觉结果可进入任务链
- 至少一个简单目标可完成闭环
- 感知、规划、执行、恢复可串起来

## 当前明确不做

- 不直接承诺复杂操作
- 不直接承诺复杂抓取策略
- 不在 P5 基础未稳时提前接大量视觉逻辑

## 与后续阶段关系

P6 做稳后，后续阶段才考虑：

- 更复杂抓取
- 更复杂场景
- 多目标 / 多步骤任务链
