# P4 完成清单

## 作用

用最短的方式判断 P4 当前“完成了什么、没完成什么、什么时候才算阶段完成”。

## 当前是否完成

- 结论：`P4 未完成`

## 已完成

- P4 正式任务入口已落地：`run_dual_arm_task`
- P4 任务配置机制已落地：`p4_tasks.yaml`
- 双臂 `dual_arms` 规划 -> 分裂左右臂执行 的软件链路已建立
- 已支持通过正式入口回固定安全位：`--target safe`
- 已修正执行等待与 cleanup 的主要工程问题

## 未完成

- 真实工位与双臂安装关系尚未完全固定
- URDF / MoveIt 与现场空间关系尚未完成对齐
- 初始位 / 安全位 / 预备位 / 任务位尚未固定
- 还没有一个在现场可重复执行且不冲突的正式双臂任务点位
- P4 真机闭环验收尚未通过

## P4 完成标准

P4 要算完成，至少要同时满足：

1. 工位固定
- 双臂安装方式固定
- 工作台、障碍物、线缆关系固定

2. 模型与现场基本对齐
- 双臂 base 相对位置与朝向可信
- MoveIt 看到的空间关系与现场基本一致

3. 固定点位完成
- 初始位
- 安全位
- 预备位
- 至少一个正式任务位

4. 正式任务闭环通过
- 双臂可进入任务
- 双臂可完成动作
- 双臂可回安全位
- 多次重复结果一致

5. 失败可恢复
- 失败后可按 SOP 恢复
- 不依赖临场拼命令
