# 硬件工位与模型对齐清单

## 作用

本清单用于在继续推进 P4 真机任务前，先把“真实空间”和“数字模型”对齐。

当前适用场景：

- 双臂真实安装方式还未完全固定
- URDF 只大致正确，但还没有与现场空间真正对齐
- P4 当前已经从“链路打通”转入“空间与点位建模”

## 目标

在恢复 P4 真机任务验收前，至少完成以下事情：

- 双臂真实安装方式固定
- base 相对位置和朝向明确
- 工作台和常驻障碍物范围明确
- URDF / MoveIt 中的空间关系与现场基本一致
- 初始位 / 安全位可以固定并重复回位

## 第一步：固定真实工位

需要先确定这些事实，不再频繁改变：

- 左臂底座安装位置
- 右臂底座安装位置
- 工作台高度
- 工作台边界范围
- 常驻障碍物位置
- 线缆活动范围和干涉区域

验收标准：

- 重新上电或重启后，双臂仍在同一套工位关系下工作

## 第二步：记录真实几何关系

建议至少记录以下信息：

- 世界参考点定义
- 左臂 base 相对参考点的位置
- 右臂 base 相对参考点的位置
- 左右臂 base 之间的相对距离
- 左右臂 base 的相对朝向
- 工作台尺寸
- 常驻障碍物的近似尺寸和位置

记录方式可以先从人工测量开始，不要求一开始就高精度。

## 第三步：校正模型

需要检查：

- 双臂 base 在 URDF 中的位置是否与现场一致
- 双臂朝向是否与现场一致
- 左右臂相对关系是否与现场一致
- RViz / MoveIt 中看到的工作空间语义是否与现场一致

当前目标不是毫米级精确，而是：

- 规划结果在空间语义上可信
- 不会出现“模型里能走，现场空间却明显冲突”的情况

## 第四步：固定点位

在模型与现场大致一致后，再定义：

- 初始位
- 安全位
- 预备位
- 任务位

要求：

- 初始位 / 安全位必须可重复回位
- 点位不能依赖“每次手动摆差不多”
- 点位定义必须结合真实空间，而不是只看 joint 数值

## 第五步：恢复 P4 真机验收

完成以上步骤后，再恢复：

- `run_dual_arm_task --task dual_prep_sync`
- `run_dual_arm_task --task dual_prep_sync --target safe`
- 工位与模型对齐恢复后：`run_p4b_acceptance --task dual_prep_sync --cycles 3`

这时再做的动作验证，才是在验证正式任务，而不是盲试点位。

## 当前阶段不该做的事

- 在工位未固定前持续修改预备位
- 在空间关系未明确前反复增大动作幅度
- 把空间冲突误判为底层链路失败
- 在 URDF 与现场明显不一致时直接推进避障或抓取

## 与后续阶段的关系

- 这份清单是当前 P4 的前置工作
- 只有真实空间与模型对齐后，P4 的任务闭环才有意义
- P5 的双臂协调与避障更依赖这一步
- P6 的视觉接入和抓取也必须建立在这一步之上
